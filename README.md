# SHAKTI CHAKRA 2026 — GitHub Pages

A single-page Navratri event website for Shakti Chakra 2026.

The layout is inspired by the overall information architecture of premium Navratri event websites: hero + CTA, countdown, about, nine qualities, experiences, record attraction, passes, gallery, venue, partners and footer. It is original Shakti Chakra branding/content rather than a copy of another site's source code.

Upload the contents of this folder to a GitHub repository and enable GitHub Pages. `index.html` is the entry point.
